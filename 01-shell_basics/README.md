# Shell Basics

This directory teaches you the fundamental commands to navigate your computer using the terminal.

## What you will learn

- **Where am I?**: Using `pwd` (Print Working Directory) to see your current location.
- **Looking around**: Using `ls` (List) to see files and folders.
- **Moving**: Using `cd` (Change Directory) to go into different folders.
- **Creating things**: 
  - `mkdir`: Make a new directory (folder).
  - `touch`: Create an empty file.
- **Managing files**:
  - `cp`: Copy files.
  - `mv`: Move or rename files.
  - `rm`: Remove (delete) files. Be careful with this one!

Think of these commands as the digital equivalent of picking up papers, putting them in folders, and organizing your desk.

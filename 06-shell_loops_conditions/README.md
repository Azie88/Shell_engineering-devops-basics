# Shell Loops & Conditions

This directory covers control structures in Bash, allowing you to control the flow of execution in your scripts.

## Concepts

### Loops
*   **For Loop**: Iterates over a list of items or numbers.
*   **While Loop**: Executes as long as a condition is true.
*   **Until Loop**: Executes as long as a condition is false (until it becomes true).

### Conditions
*   **If/Else**: Executes code based on whether a condition is true or false.
*   **Case**: A cleaner alternative to multiple if/elif/else statements when checking a variable against multiple values.

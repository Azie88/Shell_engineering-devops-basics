# Shell Engineering & DevOps Basics

Welcome! This repository contains simple exercises to help you learn the basics of using the **Shell** (the command line interface on your computer).

If you are new to programming or DevOps, think of the Shell as a way to talk to your computer by typing commands instead of clicking with a mouse.

## What's Inside?

I have broken down the learning into small sections (directories):

- **01-shell_basics**: Learn how to move around folders, create files, and copy things.
- **02-shell_permissions**: Learn how to control who is allowed to read, write, or run your files.
- **03-shell_redirections**: Learn how to send the output of one command into a file or another command.
- **04-shell_variables_expansions**: Learn how to store information (variables) and do simple math.
- **05-shell_arithmetic**: Learn how to perform mathematical operations within scripts.
- **06-shell_loops_conditions**: Learn usage of control structures like `if`, `case`, `for`, `while`, and `until`.
- **07-shell_functions**: Learn how to write modular, reusable code with functions.
- **08-shell_signals_processes**: Learn to manage processes, PIDs, background jobs, and handling signals.

Each directory has its own `README.md` file that explains what you will learn in that section.
